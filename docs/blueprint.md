# **App Name**: Harmeko Online

## Core Features:

- Menu Display: Display the coffee menu with details like description, ingredients, and price.
- Image Gallery: Allow customers to view high-quality images of the coffee and the coffee shop ambiance.
- Contact Information: Provide contact information, address, and a map for the physical store location. Provide a contact form.

## Style Guidelines:

- Primary color: Deep brown (#3E2723) to evoke the rich coffee experience.
- Secondary color: Creamy beige (#F5F5DC) for a smooth, elegant feel.
- Accent: Burnt Orange (#D2691E) for highlights and call-to-action buttons.
- Use a clean and modern grid-based layout for easy navigation.
- Simple and elegant line icons related to coffee and cafe elements.
- Subtle transitions and animations for a smooth user experience.
